📋 PDF 필드 매핑 도구 (AcroForm용)

보험금 청구서에 자동으로 입력될 필드를 클릭으로 간편하게 설정하세요

🎯 사용 방법

  1. PDF 업로드: 보험사 청구서 PDF 파일을 선택하세요.
  2. 보험사 키 입력: 영문 보험사 코드를 입력하세요 (예: HYUNDAI_MARINE, DB_INSURANCE).
  3. 빠른 필드 추가: 우측 "피보험자 (개별칸)" 버튼으로 주민번호/전화번호 개별 칸 추가!
  4. 👆 클릭 모드 (기본): 노란색 필드를 확인하고, 입력란의 왼쪽 상단을 클릭! 크기는 자동으로 설정됩니다!
  5. 🖱️ 드래그 모드: 버튼을 눌러 전환 가능. 입력란을 드래그해서 크기도 함께 지정할 수 있습니다.
  6. ⬅️ 이전 단계로: 잘못 찍었으면 계속 되돌릴 수 있습니다!
  7. 코드 생성: 모든 필드 완료 시 자동으로 코드가 생성됩니다.
