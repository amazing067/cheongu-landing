📐 PDF 좌표 측정 도구

보험금 청구서 자동기입을 위한 좌표 매핑 도구 (클릭하여 필드 위치 저장)

📌 사용 방법

  1. PDF 업로드: 보험사 청구서 PDF 파일을 업로드하세요.
  2. 페이지 선택: 여러 페이지가 있다면 해당 페이지를 선택하세요.
  3. 필드 추가: 우측 패널에서 필드명을 입력하고 "대기 중" 버튼을 클릭하세요.
  4. 좌표 클릭: PDF의 입력란을 클릭하면 좌표가 자동으로 저장됩니다.
  5. 코드 복사: 모든 필드를 저장한 후 "코드 복사" 버튼으로 설정을 복사하세요.
